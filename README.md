# BusPark

Автобус паркін есепке алу жүйесі. Оқу практикасы жобасы (2026).

Студент: Тойганбеков Бекарыс, топ РПО1-23К.

## Не істейді

Жүйеде автобустың мемлекеттік нөмірі, маркасы, жүргізушісі және техникалық жағдайы («Жарамды», «Жөндеуде», «Есептен шығарылған») сақталады. Автобусты қосуға, өзгертуге, жоюға, нөмір бойынша іздеуге болады. Деректер енгізілгенде сервер нөмір форматын, бос өрістерді, нөмірдің қайталануын және күйдің дұрыс ауысуын тексереді.

## Технологиялар

React (Vite), Node.js, Express, MongoDB (Mongoose), JWT (httpOnly cookie), Postman, Apache JMeter, GitHub Issues.

## Папкалар

```
server/    Express сервері, http://localhost:5000
  src/     app.js, server.js, models.js, seed.js, logger.js
client/    React интерфейсі, http://localhost:3000
postman/   Postman коллекциясы
```

## Алдын ала керек

Node.js (LTS), MongoDB Community Server (`mongodb://127.0.0.1:27017` мекенжайында жұмыс істеп тұруы керек), Git.

## Іске қосу (Windows, cmd)

Екі бөлек терминал қажет.

Сервер:

```
cd server
npm install
npm start
```

Клиент:

```
cd client
npm install
npm run dev
```

Содан кейін браузерде http://localhost:3000 ашыңыз.

Деректер базасы бос болса, бірінші рет қана бастапқы деректерді қосыңыз (сервер папкасында):

```
npm run seed
```

Назар аударыңыз: `npm run seed` users және buses коллекцияларын толық тазалап, қайта жазады. Деректері бар базада оны іске қоспаңыз.

## API

Кіргеннен кейін токен `token` атты httpOnly cookie ішінде сақталады (2 сағат). Төмендегі «жүйеге кірген» дегені cookie бар сұраныс.

| Әдіс | Маршрут | Кім істей алады |
|---|---|---|
| POST | /api/auth/login | барлығы |
| POST | /api/auth/logout | барлығы |
| GET | /api/auth/me | жүйеге кірген |
| GET | /api/buses (іздеу: `?search=101`) | жүйеге кірген |
| GET | /api/buses/:id | жүйеге кірген |
| POST | /api/buses | админ |
| PUT | /api/buses/:id | админ, диспетчер, механик |
| DELETE | /api/buses/:id | админ |

Postman коллекциясы: `postman/BusPark.postman_collection.json` (Import жасап, алдымен «1 Login» сұранысын орындаңыз).

## Баптаулар

JWT кілті `JWT_SECRET` ортақ айнымалысынан алынады, ол көрсетілмесе, оқу мақсатындағы әдепкі кілт қолданылады. Дерекқор мекенжайы `MONGO_URL` айнымалысымен өзгертіледі. Логтар `server/logs/app.log` және `server/logs/error.log` файлдарына жазылады, олар репозиторийге жүктелмейді.
